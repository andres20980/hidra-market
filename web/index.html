Red team: what we found and fixed

An adversarial agent lane attacked the contract with near-sandbox tests before release. Three real issues; each is fixed, pinned by a test and replayed against the upgraded testnet contract.

  • Storage griefing An oversized task id or result hash made the contract pay the storage stake and could freeze an honest escrow. Fix: task id ≤ 64 B, result hash ≤ 128 B. Test: contract/tests/test_storage_griefing.rs. Testnet: 129-byte hash rejected, round still Settled — 4D9PY6cT…
  • Round spam Many minimum-deposit rounds could drain the balance that backs open escrows. Fix: post_task keeps a storage reserve. Test: contract/tests/test_round_spam.rs. Testnet: guarded code deployed — 3jzCb1cV…
  • Zero price A bid of 0 scored 0 and won whatever the reputation. Fix: reveal requires price > 0. Test: contract/tests/test_zero_price_bid.rs. Testnet: price-0 reveal rejected, honest bidder paid — DSw8EFwm…
